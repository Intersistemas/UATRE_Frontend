   ──────────────────────────────
   AGREGADO:
   - Después de cargar denuncias, llama al endpoint /DenunciasEstados
   - Crea un mapa: { appDenunciasId: {estado, fecha, observaciones} }
   - Combina estados con denuncias usando el ID
   - Mantiene el estado más reciente si hay múltiples
   - Agrega propiedades: estado, fechaEstado, observacionesEstado
   
   Código clave:
   ```javascript
   pushQuery({
     action: "GetEstados",
     params: {},
     onOk: async (responseEstados) => {
       // Crear mapa de estados
       const estadosMap = {};
       estados.forEach(item => {
         estadosMap[item.appDenunciasId] = {
           estado: item.estado,
           fecha: item.fecha,
           observaciones: item.observaciones
         };
       });
       
       // Combinar con denuncias
       const dataConEstados = denuncias.map(denuncia => ({
         ...denuncia,
         estado: estadosMap[denuncia.id]?.estado || "Sin datos"
       }));
     }
   });
   ```

================================================================================
FLUJO DE DATOS COMPLETO
================================================================================

1. CARGA INICIAL
   ↓
   useDenuncias → pushQuery("GetList") → /AppDenuncias
   ↓
   Recibe TODAS las denuncias (sin paginación)

2. FILTRO POR ÁMBITO
   ↓
   Si usuarioAmbito existe:
     → applyAmbitoFilter(denuncias, usuarioAmbito)
     → Filtra por seccional o delegación
     → Guarda en dataOriginal

3. CARGA DE ESTADOS
   ↓
   pushQuery("GetEstados") → /DenunciasEstados
   ↓
   Recibe todos los estados
   ↓
   Crea mapa: { appDenunciasId: {estado, fecha, observaciones} }
   ↓
   Merge con denuncias: denuncia.estado = estadosMap[denuncia.id].estado
   ↓
   Actualiza dataOriginal con estados

4. FILTROS MANUALES (si aplica)
   ↓
   Filtro por Estado: item.estado === filtroEstado
   ↓
   Filtro por Fecha Desde: item.fecha >= filtroFechaDesde
   ↓
   Filtro por Fecha Hasta: item.fecha <= filtroFechaHasta
   ↓
   datosFiltrados = datos después de todos los filtros

5. PAGINACIÓN CLIENT-SIDE
   ↓
   startIndex = (pageIndex - 1) * pageSize
   endIndex = startIndex + pageSize
   dataPaginada = datosFiltrados.slice(startIndex, endIndex)
   ↓
   Actualiza list.data con dataPaginada
   ↓
   Actualiza list.pagination.count con total filtrado

6. RENDER
   ↓
   DenunciasTable muestra dataPaginada
   ↓
   Usuario puede:
   - Cambiar página → Re-paginar sobre datosFiltrados
   - Cambiar filtros → Volver al paso 4
   - Limpiar filtros → Volver al paso 5 (sin filtros)

ESTRUCTURA DE DATOS USUARIO
================================================================================

Objeto usuario esperado:
```javascript
{
  ambitoTodos: null | true,
  ambitoSeccionales: {
    ids: [104491, ...]
  } | [104491, ...] | null,
  ambitoDelegaciones: {
    ids: [163, ...]
  } | [163, ...] | null,
  ambitoProvincias: null | {...}
}
```

Lógica de prioridad:
1. Si ambitoTodos → Sin filtro (todas las denuncias)
2. Si ambitoSeccionales → Filtrar por seccional específica
3. Si ambitoDelegaciones → Filtrar por delegación + sus seccionales
4. Si ambitoProvincias → Sin implementar (sin filtro)
5. Si ninguno → Sin filtro
